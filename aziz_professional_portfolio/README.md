# Aziz Ben Salah — Professional Portfolio

A professional static portfolio built with HTML, CSS and JavaScript.

## Included
- Real profile photo supplied by Aziz Ben Salah
- 33 real credential assets
- Certificate thumbnails generated from the uploaded certificate PDFs
- Direct certificate document links
- Verification links where present on the original certificate
- Projects, experience, skills, leadership and contact information

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
The project is static and can be published with GitHub Pages, Vercel, Netlify or another static host.
GitHub Pages supports static `index.html` sites. See:
https://docs.github.com/en/pages/quickstart

## Important
The certificate files are included as supplied. No credential IDs or verification URLs were invented.
